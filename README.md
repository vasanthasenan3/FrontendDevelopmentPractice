# 🚀 Frontend Development Practice

A collection of frontend practice projects built using HTML, CSS, Bootstrap, and JavaScript. This repository documents my learning journey through webpage development, user interface design, and basic JavaScript functionality.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap
* JavaScript

## 📂 Projects

### 1. Perfume Landing Page

**Technologies:** HTML, CSS

A simple perfume website featuring product images, navigation links, an About Us section, and contact information.

**Concepts Practiced:**

* HTML page structure
* CSS styling
* Image integration
* Webpage section layouts

### 2. Company Web Page

**Technology:** HTML

A company website introducing company services and technologies, with a separate course registration page.

**Concepts Practiced:**

* Headings, paragraphs, and lists
* Images and embedded YouTube videos
* HTML tables
* Navigation links
* Forms, input fields, radio buttons, dropdowns, and file uploads

### 3. JavaScript Calculator

**Technologies:** HTML, CSS, Bootstrap, JavaScript

An interactive calculator designed to perform basic arithmetic operations through a simple user interface.

**Concepts Practiced:**

* JavaScript functions
* Event handling
* DOM manipulation
* Arithmetic operations
* Interactive user interface design
